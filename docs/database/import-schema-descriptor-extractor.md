# PostgreSQL import schema descriptor extractor

`mapilio:extract-import-schema` is a disabled-by-default, source-only operator command. It reads only PostgreSQL catalog metadata and writes a private descriptor compatible with [descriptor v1](import-schema-fingerprint.md). It never resolves the application/target connection.

The source connection policy is fixed in application configuration to the single connection name `legacy_pgsql`; there is no environment-expandable allowlist. The resolved connection must use `pgsql` and must have a distinct, unambiguous PostgreSQL host/port/database endpoint from the configured default connection when that default is PostgreSQL. Configure lowercase `MAPILIO_IMPORT_SCHEMA_SCHEMA` and `MAPILIO_IMPORT_SCHEMA_TABLE`, enable the feature, and run with `--confirm-read-only-source --output=descriptor.json`. Production is refused before connection or filesystem work.

The action starts a read-only transaction, verifies `transaction_read_only=on`, and applies bounded local statement and lock timeouts before each metadata query. It verifies an ordinary `pg_catalog.pg_class` base table, matches the complete visible `pg_attribute` column count to ordered `information_schema.columns` metadata, and rejects domains, arrays, user-defined types, generated/identity columns, and types outside the v1 `pg_catalog` allowlist. No rows, values, timestamps, connection details, or infrastructure data are emitted.

Output is created under an owner-private 0700 directory and published as a 0600 JSON regular file using atomic same-directory hard-link publication without overwrite. This guarantee assumes the parent directory is owner-controlled and is not renamed or replaced while the command runs; hostile same-UID processes remain outside the protection boundary. After destination verification, temporary-link cleanup is best effort and cannot turn a successful publication into failure. The CLI emits only check names and sanitized reason codes. Tests use mocked connections and never access a real database or network.
