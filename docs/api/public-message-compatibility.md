# Public API Message Compatibility and Localization Readiness

Repository-evidence-only inventory of messages and envelopes reachable from explicit public routes, controllers, middleware, requests, and domain exceptions, plus compatibility tests. Dynamic legacy dispatch, UI text, production traffic, and internal-only job logs are excluded from the public contract. A backend assertion proves repository behavior under its test setup, not real-client parsing.

## Classification

- **Preserve now** — retain current status, text, and envelope while clients may depend on them.
- **Future version** — add a stable machine-readable code while retaining current text/envelope during the compatibility window.
- **Keep internal** — do not expose or expand it as a public contract.
